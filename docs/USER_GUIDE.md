# 使用说明

## 首次配置

打开应用后，等待“本地服务已连接”。启动失败时使用重试，并从日志入口查看原因。

首次启动向导依次介绍本地环境、云端连接和可选短句测试；可以跳过连接进入离线编辑。短句测试只有点击后才会提交云端并产生相应账户用量。

在云端连接中配置：

- 连接名称：便于区分不同账户或项目。
- 服务根地址（Base URL）：填写百炼控制台或官方接入文档提供的 HTTPS 服务地址。
- API Key：与上述服务地址对应的百炼密钥。
- 默认模型和音色：默认使用 `qwen-audio-3.1-tts-plus` 与 `longanhuan_v3.1`。
- 默认并发及可选参考单价在高级设置中调整。

工作流不要求手动选择业务地域或填写业务空间 ID。保留应用提供的服务地址，或粘贴账户对应的百炼服务根地址；地址必须使用 HTTPS，不能填写完整合成接口路径，也不能使用文本聊天模型接口地址。应用保存默认连接，新建项目和导入的台词会沿用它；已有台词明确指定的连接不会被改写。不同账户的项目可在台词或角色配置中切换连接。

“测试连接”执行只读检查；修改配置或密钥后先保存，再测试。实际效果通过输入短句并生成验证，这会提交云端请求并可能产生账户用量。密钥不会显示在历史记录中。Linux 系统钥匙环不可用时，会提示“仅本次使用”；不会写入明文配置文件。

## 声音库与试听

声音库汇集百炼官方目录中的 157 个模型/音色条目、153 个唯一音色 ID。相同音色可能适配多个模型；在音色卡片的模型选项中确认目标模型，不能只根据相似的名称判断兼容性。

- 搜索名称、音色 ID、模型、语言或风格标签；再按模型、声线、语言筛选。每张卡片直接显示音色 ID，点复制图标即可复制。
- 使用“我的收藏”整理常用官方音色；“我的声音”查看本地保存的克隆和设计音色。
- 点击卡片试听按钮播放样音。官方静态样音首次点击时下载并缓存；缓存后可离线试听。该试听不会调用语音合成，也不消耗生成额度。
- 选择台词后点击“使用”，将音色应用到所选句子。需要切换模型时，界面会提示并随音色一起切换。
- 克隆声音的试听标记为参考录音，不代表模型合成效果；设计声音只有服务端返回试听样音后才可试听。

声音名称、模型范围和试听地址来自[阿里云官方音色目录](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。

## 台词与角色

支持粘贴长文本、自动分句、手动拆分与合并、拖动/调整顺序、搜索替换、批量选中和应用参数。每句台词拥有独立参数。SRT/VTT 导入保留时间码，并将字幕长度设为目标时长。

角色是项目中的声音配置。全局声音库保存可复用配置；克隆音色和设计音色绑定其创建时的连接及目标模型，不能任意换成另一模型使用。

修改台词后，既有音频仍可在历史中试听。后台旧任务完成时如果台词已变化，结果仅加入历史，不自动替换当前选择。

## 声音克隆与声音设计

克隆之前必须确认已获得参考声音授权。使用清晰、连续、少背景噪声的参考录音；应用会检查大小、格式和时长，再调用云端创建音色。克隆效果不能保证完全还原原声。

声音设计使用音色描述和试听文本创建音色。新音色可能处于审核或部署状态，使用刷新查询状态，只有服务端确认可用后才能合成。

删除本地声音配置不会删除云端音色，也不会删除历史录音。

## 情绪与导演

情绪、语言和自然语言指令交给百炼模型解释。原生语速、音调和音量使用官方参数。SSML 仅在当前模型和音色支持时启用，不能把不支持的标签当作精确控制。

导演模式生成可编辑的分段计划。请在预览中检查每个分段的文本、指令和停顿，再应用到台词。首版的解析是规则和模板，不会伪装成另一个大语言模型。

重音和情绪属于生成建议，不能保证字级一致性。时间轴里的速度、增益和裁剪则是对已生成音频的本地非破坏性处理。

高级精细控制支持按词插入句内停顿（50–10000 毫秒）和普通话发音修正，例如 `重庆=chong2 qing4`。同一词语每次出现都会应用。模型或音色不支持时不会默默忽略设置，而是提示切换或移除。

## 生成任务与用量

同一句同一参数的重复点击不会同时提交重复任务。默认最多两个并发请求；可按账户配额降低。

任务状态区分排队、生成中、请求取消、已取消、失败和结果不确定。WebSocket 取消在收到服务端结束确认后才显示已取消。HTTP 请求中途断开时，服务端可能已经生成和计费，因此不会自动重复提交。

实际用量采用服务端返回值。字符和 Token 计费不能混用。参考费用仅按你填写的单价计算，不能代替百炼账单；未填写单价时不显示虚构金额。

## 时间轴、视频与导出

每个片段保存自己的位置、裁剪范围、轨道、增益、淡入淡出和速度；这些修改不覆盖源音频。原始音频与导出文件分别保管。

时间轴提供多选、跨轨移动、片段边缘与播放头吸附、边缘裁剪、淡入淡出手柄、分割、复制、静音、微调和右键菜单。拖动时先预览，松开后一次保存。使用 Alt 可在拖动时暂时越过吸附；吸附开关可持续关闭。片段可按全部内容或选区适配缩放。方向键微调 10 毫秒，Shift 加方向键微调 100 毫秒；B 分割，Ctrl+D 复制，M 静音，Delete 移除选中片段，S 切换吸附。移除片段不会删除源音频。

当前提供线性淡入与淡出；交叉淡化及自定义淡化曲线尚未实现。整体交互参考 [Premiere Pro 片段吸附](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/snap-clips.html) 和 [Audition 多轨片段编辑](https://helpx.adobe.com/audition/desktop/mixing-multitrack-sessions/arranging-editing-multitrack-clips.html)、[淡化控制](https://helpx.adobe.com/audition/desktop/mixing-multitrack-sessions/clip-volume-matching-fading-mixing.html)；当前功能范围不等同于这些商业软件的全部能力。

完整时间轴试听和最终导出采用同一渲染逻辑。导出支持响度归一化及防削波。WAV 默认 48kHz、24-bit PCM；MP3 为 192kbps。

视频导入会生成兼容代理文件；长视频处理在后台进行。视频与配音共享播放位置。目标时长提示用于发现配音过长或过短，可以先调整片段速度并试听，再决定是否重新生成。

桌面导出使用系统保存对话框，现有文件不会无提示覆盖。导出成功后可打开文件夹。项目备份包含项目数据库和重要素材，不包含 API Key。

## 保存与恢复

编辑自动保存，并支持撤销/重做。关闭软件前确认保存状态；应用异常退出后，中断的云任务保留记录，不自动重新收费生成。

完整项目包可导入为一个新项目，不覆盖原项目。缺失素材以明显状态提示，可选择文件重新连接。卸载软件不应主动删除用户项目。

项目列表中每个项目都有“重命名”和“删除”操作。删除前会说明文件保留策略并要求确认；确认后项目进入应用回收站，音频和历史文件不会删除。打开“项目回收站”可恢复原项目。正在生成、导出或导入的项目需要等待任务结束，或先主动取消任务，再删除。

导入 TXT/SRT/VTT 时，新台词会继承现有连接的模型和音色（优先已配置密钥的连接），原有台词设置保持不变。多账户制作时，可在属性栏或角色配置中切换连接。

## 常见问题

- **鉴权失败**：确认 API Key 与服务根地址属于同一百炼账户和业务配置；连接表单无需另外填写业务空间 ID 或选择地域。
- **听不到官方音色样音**：先检查网络是否能访问官方音频资源，再重试。已缓存的样音可离线播放；“暂无样音”的音色不会偷偷触发收费生成。
- **音色不可用**：检查目标模型、创建连接和审核状态，必要时刷新声音。
- **请求过于频繁**：降低并发，等待配额恢复后再操作。
- **系统代理问题**：0.1.1 起兼容常见代理软件导出的 `socks://127.0.0.1:7897` 格式。请保持代理软件运行；修改代理设置后重新启动工作站。若显示代理连接失败，检查端口和软件状态，不必改动模型或项目数据。
- **结果不确定**：检查历史、任务请求标识及百炼用量，再决定是否重试。
- **不能离线生成**：远程合成需要网络；项目编辑、现有音频试听和导出仍在本地完成。
- **应用启动失败**：查看本地日志。安装包不完整时应重新安装完整版本，不能只复制一个后端可执行文件。
